Usage
1. Copy the files into your website's public/images/tai-forge folder.
2. Use HTML/CSS for all text and CTAs, never embed headlines in the graphics.
3. Desktop hero: CSS background or Next Image fill; use object-position:center.
4. Mobile hero: switch source to mobile variation via picture or media query.
5. Service SVGs are decorative illustrations; if adjacent service title is visible, alt can be empty.
6. Optimize loading: hero high priority, service images lazy loaded, width/height specified.
7. Do not call the generated monitoring visualization a real customer dashboard or report performance metrics from it.
